# AI Adoption & User Behavior Analytics

This project analyzes how people use AI assistants across different countries, age groups, professions, subscription plans, and usage patterns.

The project covers the complete data analytics process, from data cleaning and SQL analysis to Power BI dashboard creation.

## Tools Used

- Excel
- Python
- Pandas
- NumPy
- MySQL
- SQL
- Power BI

## Project Workflow

Excel → Python → MySQL → SQL → Power BI

## What I Analyzed

- AI / LLM usage by country
- User demographics and professions
- Subscription plans
- Usage frequency and purpose
- Daily usage time
- Satisfaction, accuracy, and response quality
- Recommendation behavior
- Preferred AI features
- Monthly usage trends

## Dashboard

The Power BI dashboard has two pages:

- **Overview** – Overall AI adoption and key metrics
- **Behavior** – User behavior, usage patterns, satisfaction, and preferences

## Project Files

- `data` – Source Excel file and cleaned CSV
- `python` – Data cleaning notebook
- `sql` – SQL analysis queries
- `powerbi` – Power BI dashboard
- `screenshots` – Dashboard screenshots
